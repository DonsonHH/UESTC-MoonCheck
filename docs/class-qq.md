# 班级情况登记与 QQ 提醒

班级功能仅在私有管理端 `/admin/class-bot` 提供。用户端没有班级页面或入口，学生账号（包括班委）也不能调用班级名单接口。管理员选择具有学校班委权限的托管账号执行管理操作。

管理员先选择班委账号，点击“读取班委权限与今日名单”。管理端读取名单、保存设置仅复用现有学校会话；若会话失效，请由该账号本人在“账号连接”更新学校验证，管理端不会为此提交学校密码或消耗后台重登次数。系统检查校方 `class-cadre/my-classes` 返回的实际权限，只展示该账号获准管理的班级。不保存全班电话、宿舍或完整历史名单。

## 每日情况说明

在名单中勾选固定的同学，开启每日登记并保存。流程在班委本人的自动签到获学校确认后执行；它使用学校的“填写情况说明”，并非定位签到。班委账号暂停、权限失效、学校时段未开放或目标已有学校记录时，不会提交。

当前登记内容为管理员确认的“校内／学习”，说明采用当天日期与同一事实的不同表述，例如“2026年10月26日：今日在校内学习，按实际情况登记。”请仅在该说明与实际情况一致时开启，情况改变时暂停或移除对象。学校记录以真实返回的状态展示，不把情况说明标成定位签到成功。

每个同学每天提交前先保存防重复记录。网络超时或结果不明时保留待复查状态，重启也不会重复提交。刷新班级记录会对照当天校方状态，显示学校已经登记的结果，同时保留原始请求是否收到响应的证据；历史日期不使用今天的记录确认。学校开放时段与应用的 21:06–23:24 范围同时生效。

## QQ 官方机器人

在管理端输入 AppID、AppSecret 并启用，凭据加密保存且不回显。点击“核验身份”，再复制管理端生成的 HTTPS 回调地址，填入 QQ 开放平台的 Webhook 配置，订阅群 @ 消息和单聊消息。回调使用专属地址、Ed25519 验签和事件去重；不托管个人 QQ 登录。

先选择班委账号并保存每日安排，再生成班级群绑定码。在班级群 @机器人发送 `绑定班级 绑定码`，10 分钟内有效且只可使用一次。完成后刷新管理端，由群主授予机器人管理员和主动发言权限。整个班级只需绑定一次，不需要逐人绑定。绑定或更换群只更新发送目标，保留 21:05 和 23:10 提醒的开关状态。已绑定时可用“检查群连接”发送普通消息，不消耗 @全体额度。机器人凭据和回调配置位于折叠的“机器人连接设置”内。

管理员可单独开启“每日 21:05 在班级群提醒签到”。开启后，每天北京时间 21:05 在正式群 @全体，提醒打开「成电智慧学工」完成晚安打卡；不读取学校名单、手机号或定位，也不执行签到。服务短暂重启仅在 21:11 前补发，同一天重启或反复检查不会重复提醒。新配置默认关闭，由管理员开启；与 23:10 提醒独立。未绑定班级群时不向其他群发送。

班级通知无需逐人绑定。每天北京时间 23:10 读取当天全部班级记录，将 `PENDING` 和 `NOT_CHECKIN` 计为未完成，在正式班级群 @全体，并列出这些同学的姓名、学号及校方提供的宿舍信息。已签到、情况已登记、免签到者不列入名单；不附电话，也不把未知状态当成未签到。

机器人需要 QQ 群管理员身份，才可发送真正的 @全体。若 QQ 拒绝，保留实际失败码和站内统计。只有平台明确返回 @全体次数超限（40034142）时，才发送一次标注“@全体额度不足”的原消息正文，并记为“消息已发送、未触发 @全体”，不伪装成 @全体成功。取消或时间过期后不会继续降级发送。群消息采用已实测可渲染交互标签的 Markdown 格式。服务短暂重启可在 23:16 前补查，每天只发送一轮，发送结果以 QQ 回执及群内实际显示为准。测试群始终不接收正式班级名单。

## 个人提醒

用户在“账号连接”卡片的 QQ 提醒行点击“设置提醒”，或从账号菜单进入 `/app/reminders`。卡片显示实际绑定和启用状态；设置页可返回账号连接。添加机器人，生成绑定码，私聊发送 `绑定 绑定码`。绑定成功不会自动开启提醒；回到网页刷新连接、勾选提醒及托管说明后保存。每天 23:10 只向该绑定用户发送本人的学校签到状态。默认不启用，不向其他同学公开个人状态。

用户可关闭提醒、解除绑定，或向机器人发送“取消提醒”。学校查询失败时说明未能核实，不谎报签到成功。QQ 提醒失败不会修改学校结果或再次提交签到。

## 接口依据

- [学校原班级页面](https://jzsz.uestc.edu.cn/daily-checkin-h5/index.html?appId=294#/pages/student/class-check-in/home/index)：实际权限、记录、情况类型及填报接口。
- [QQ 访问凭证](https://bot.q.qq.com/wiki/develop/api-v2/dev-prepare/access-token.html)：服务器凭证与续期。
- [QQ 消息收发概述](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/overview.html)：主动消息、场景权限及频率。
- [QQ 安全和授权](https://bot.q.qq.com/wiki/develop/api-v2/dev-prepare/interface-framework/sign.html)、[Webhook](https://bot.q.qq.com/wiki/develop/api-v2/dev-prepare/event-emit/webhook.html)：回调校验与验证应答。

上游现有通知模块参考的是飞书 Webhook；此处 QQ 官方接口、班委权限、加密映射和防重复流程为本部署版新增实现。

未绑定正式群或群提醒关闭时，23:10 核对仍保留在站内，不把人数或名单发到测试群。包含成员 @ 的消息使用 Markdown，避免把交互标签当成普通文本。

管理端仅保留班级群绑定、普通连接检查、21:05 提醒、23:10 未签到提醒和指定同学的情况登记。原演练入口与试验记录不再显示；后台仍保留旧群的隔离标记和原始运行记录。
