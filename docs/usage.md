# 使用指南

## 连接微信授权

管理员启用新版授权后，进入 **账号连接** 页面，阅读并确认令牌托管说明，再使用已在「成电智慧学工」绑定本人学校账号的微信扫码。授权页显示「应用宝」，用于获取学校小程序登录码；如询问是否允许运行小程序，需确认这项权限。

完成授权后，后台会校验微信绑定与学校登录是否为同一学号，并在每次提交前取得新操作票据。访问令牌会按需续期；授权撤销或刷新被明确拒绝时，需要本人重新扫码。可在该页面移除微信授权，账号、位置和历史记录保留，自动计划等待重新授权。

### 一次授权后能否每天自动执行

可以。完成首次经学校确认的签到并开启每日计划后，后台独立运行，不需要每天打开本站或重新扫码。退出本站、关闭浏览器和服务器正常重启都不会撤销已保存的授权。

微信访问令牌到期时，后台使用加密保存的刷新令牌续期；每次签到另向学校申请新的短期、一次性操作票据。不会把同一张票据保存到第二天使用。初次扫码若未取得刷新令牌，页面会明确提示失败，不把只能短时使用的凭据显示为完成授权。

微信授权被撤销、刷新令牌失效，或学校另行要求验证码、二次验证时，需要本人重新完成相应验证。微信授权与学校登录分别恢复，网站的 24 小时密码校验缓存不决定这两者的有效期；不能承诺一次扫码永久免验证。

学校验证码、二次验证与微信授权分别独立。学校要求更新登录时，继续在学校原页面完成。若未启用新版授权而仍显示 **请在微信小程序完成签到**，按提示在原小程序签到后同步记录；重新验证密码不会替代小程序票据。

运行详情显示学校原始业务码与脱敏后的信息。明确拒绝显示为“学校已拒绝提交”；超时等无法判断是否送达的情况才显示待复查。历史记录按已有响应解释，原始记录不改写。

## 第一次使用

1. 输入学号和学校密码，阅读并确认托管说明。学校要求验证码或二次验证时，在弹出的学校原页面完成。
2. 在“账号连接”中确认令牌托管说明，由本人扫码，完成后点击“下一步：设置计划”。
3. 在“每日计划”选择本人实际所在组团和偏好时间，保存后回到今日安排。时间浮动默认前后 5 分钟，位置浮动默认半径 10 米。
4. 在 21:06–23:24 内回到“今日”，点击“完成首次签到”。系统会在提交前同步校验学校时段、地点和当日记录。白天会提示等待首签时间；若今天已在学校端完成签到，无需重复提交，明晚再通过本站完成首签。
5. 学校确认后，在“每日计划”开启自动执行。首页会显示当天预计时间，之后无需每天点击检查。

微信明确拒绝当前访问凭据时，系统会尝试刷新并重建一次连接；仍不可用时，账号连接页会提示重新扫码。普通网络失败保留授权，按临时故障恢复。

第一次扫码前，先在微信「成电智慧学工」绑定同一学号。使用同一台手机访问本站时，可展开二维码下方的帮助，保存二维码后在微信扫一扫中从相册识别。学校验证和微信连接同时失效时，先点“完成学校验证”，再连接微信。

## 日常状态

| 首页状态 | 操作 |
| --- | --- |
| 今晚已安排自动签到 | 等待计划执行；需要时查看或修改计划。 |
| 今日已完成 | 当天已有学校记录，明天继续安排。 |
| 需要学校认证 | 点击“重新验证学校登录”，完成本人验证。 |
| 今日结果待确认 | 点击复查；系统保留原提交，不重复发送。 |
| 今日任务需要处理 | 查看原因，处理后在开放时段明确手动补签。 |
| 请调整偏好时间 | 附近窗口已满，选择另一偏好时间。 |
| 托管已暂停 | 在设置中重新启用。 |

## 每日安排

每天以保存的偏好时间为中心，在前后 5 分钟与校方开放窗口的交集中选择一个空闲分钟，再加 0–19 秒错峰。当天安排持久化，刷新或重启不改变；次日重新分配。最后几分钟保留作一次延后重试，界面展示当日实际安排。

计划修改需要保存才会生效；点导航或浏览器返回／前进离开时，会提醒未保存的修改。若计划已在另一个页面或设备更新，当前未编辑的表单会同步；正在编辑的草稿会保留，并提示先载入最新计划。保存时后端也会核对配置版本，避免旧页面覆盖刚保存的调整；管理端发生冲突时同样可“载入最新配置”。

开启位置浮动后，每天在中心点半径 10 米的圆内生成一个固定点。系统检查整个圆和最终点是否属于该账号的校方围栏，不会把不合格的位置自动挪入围栏。关闭浮动则使用保存的中心点。

## 验证、记录与资料

学校密码修改后，退出并使用新密码重新登录。普通登录可以复用本站已验证的会话；“重新验证学校登录”会主动更新学校认证，成功后解除本人账号的后台重登限制。

运行记录默认显示北京时间今天及前两天，每批最多 30 条。点击“加载更多记录”查看较早历史，点击“只看最近三天”回到近期。记录不会因为折叠而删除。

账号菜单中的外观选择默认跟随系统，手动选择保存在当前浏览器。“帮助与托管说明”与首次登录展示同一份说明。

暂停计划保留资料；删除学校账号清除关联凭据、Cookie 和运行记录。用户资料、备份与去标识保护状态的处理以托管说明为准。
