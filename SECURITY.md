# Security and private data

Do not include school credentials, browser fingerprints, cookies, databases or encryption keys in Issues or pull requests. Describe reproducible problems with secrets removed. Keep the encryption key paired with its databases on private storage.

Public deployment requires HTTPS. Administrators manage all accounts in their own instance; ordinary users manage only their own. An account label or shared URL is not authorization to use another person's school identity.

This release does not automatically answer school MFA or CAPTCHA challenges. School changes can require manual authentication or a software update.
